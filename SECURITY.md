# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.0.x   | Yes       |
| 1.6.x   | Security fixes |
| < 1.6   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in m1nd, please report it responsibly.

**Email:** max@cosmophonix.com

**Response timeline:**
- Acknowledge within 48 hours
- Fix for critical issues within 7 days
- Advisory published after fix is available

**Scope:** All workspace crates (`m1nd-core`, `m1nd-ingest`, `m1nd-control`, `m1nd-mcp`, `m1nd-runnerd`, `m1nd-openclaw`), `m1nd-ui`, the `@maxkle1nz/m1nd` npm package, and their dependencies.

Please do NOT open public GitHub issues for security vulnerabilities.
